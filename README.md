# Portfólio Profissional 

## Descrição do Portfólio
Página web pessoal desenvolvida para apresentar meu perfil acadêmico na área de Desenvolvimento de Sistemas, minhas principais habilidades tecnológicas, projetos práticos e canais de contato profissional.

## Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização personalizada, transições e animações.
- **Bootstrap 5:** Layout responsivo, barra de navegação, carrossel e sistema de cards.
- **Devicon:** Biblioteca de ícones para representação das ferramentas.

## Link do Site Publicado
[Acessar Portfólio Online](https://github.io)

## Funcionamento do Projeto
O site opera em formato de página única (*One-Page*), dividida nas seções **Perfil**, **Projetos** e **Contato**. A barra de navegação superior fixa (`sticky-top`) permite navegar suavemente entre os blocos, enquanto o grid do Bootstrap adapta a exibição para computadores e dispositivos móveis.
