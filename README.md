## 📝 Descrição do Portfólio
Este é o meu portfólio pessoal desenvolvido como atividade da Agenda 15. Criei esta página para apresentar um pouco sobre mim, o que estou estudando na área de Desenvolvimento de Sistemas, os projetos que já fiz e minhas formas de contato.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Para criar a estrutura e os textos da página.
* **CSS3:** Para personalizar as cores em roxo, tamanhos e animações.
* **Bootstrap 5:** Para organizar o menu, o carrossel de fotos e os cards responsivos.
* **Devicon:** Para adicionar os ícones das ferramentas.

🟣 **[Clique aqui para acessar meu Portfólio Online](https://renatadsg.github.io/portfolio_profissional/)**

## ⚙️ Explicação do Funcionamento do Projeto
O site funciona em uma página única dividida em três partes principais: **Perfil**, **Projetos** e **Contato**. O menu fixo no topo facilita a navegação, levando direto para a seção escolhida. Graças ao Bootstrap, a página se ajusta sozinha tanto na tela do computador quanto no celular.

## ✨ Descrição do Recurso Novo Adicionado
1. **Animações nos Cards (Hover):** Quando passamos o mouse por cima dos cartões de habilidades ou de projetos, eles dão uma leve subidinha.
2. **Card de Projeto Real (Landing Page):** Atualizei a seção de projetos incluindo o site *"Entretenimento Digital"*, que desenvolvi na atividade anterior, com link direto para ele.

## 💻 Explicação de Como Esse Recurso Foi Implementado
* **Nas animações:** Usei a propriedade `transition` junto com `:hover` e `transform: translateY(-8px)` no arquivo `style.css/HTML` para criar o movimento suave.
* **No novo projeto:** Usei o sistema de grid e cards do Bootstrap no `index.html`, adicionando uma captura de tela real e vinculando o botão ao link do GitHub Pages do projeto anterior.
